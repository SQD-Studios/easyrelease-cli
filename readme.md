# easyrelease-cli

A tool for easily releasing versions to **Modrinth**, **GitHub** and **HangarMC**.

### Installing

Installing this is pretty easy! You first need to download the zip file from the releases tab. You then should put it
into a folder. You should then unzip it and put the **libs** and **bin** folder to the root of that folder and delete
the zip file. You should then add that folder's path + the bin folder to _PATH_ (The enviroment variable). E.g., the
finished path should look something like: **C:/easyreleases/bin**.

Congrats, if you did this process correctly you can now use **easyrelease** in your Command Line!
